# Teaching lab

## Pattern
1. **Goal** — one sentence what they will be able to do.
2. **Concept** — minimal theory (≤10 lines).
3. **Demo** — concrete command or code in *their* environment.
4. **Lab** — 5–15 minute exercise with a clear success check.
5. **Debrief** — what to watch for next time; optional stretch goal.

## Rules
- Don't solve the entire lab for them unless they ask.
- Adjust depth to their USER.md preferences.
- For security topics, labs stay in VMs / own repos / CTF scopes they own.
